There is no need to install the Windows WordPad application to write a simple document on a Mac. EDTRpad provides a browser-based option for formatted writing and DOCX editing.

## Start in your browser

[Open EDTRpad](/pad), create a document and use headings, lists and the formatting toolbar. If you already have a Word file, choose **File → Open** and select the DOCX from your Mac. Follow the [DOCX opening guide](/guides/open-docx-online) before importing a complex template.

For common shortcuts, use Command instead of Ctrl: Command+B for bold, Command+I for italic and Command+Z for undo. The [shortcut reference](/guides/wordpad-keyboard-shortcuts) lists the supported combinations.

## Choose between browser and desktop tools

A browser editor is convenient for a letter or quick file edit. A desktop word processor may suit you better when you need reliable offline access, specialized page layout or complex Office features. EDTRpad is not a native Mac version of Microsoft WordPad.

Fonts installed on your Mac can differ from those available on the recipient’s device. Review a DOCX after opening it in the destination app, or use PDF when the recipient only needs to read the finished pages.

## Keep your work accessible

Guest documents stay in the current browser profile. Opening a different browser on the same Mac does not automatically bring them across. Sign in for account sync or transfer an exported file.

Use [DOCX export](/guides/export-to-word-docx-online) to create an editable copy and the [printing guide](/guides/print-document-browser) before printing or saving through the system print dialog.
