WordPad was Microsoft’s lightweight Windows document editor. People used it for simple formatted text without the full workflow of a larger office suite. EDTRpad is a separate browser-based editor, not a Microsoft release of that application.

## Why do people still search for WordPad?

The familiar name often means a straightforward task: write a letter, open a text document, apply basic formatting or print a page. Some people are also looking for an application that disappeared after a Windows update.

Microsoft documents its removal starting with Windows 11 24H2. The [Windows 11 guide](/guides/wordpad-windows-11) links to the official notice and explains what to do with existing files.

## What does online WordPad mean here?

On wordpad.info, the editor is EDTRpad, developed by 312. It offers formatted writing, tables, images, DOCX import and export in the browser. It has a toolbar and a slash command menu.

Guest writing saves in the current browser. An optional account adds sync across devices. These are features of EDTRpad, not statements about the old Windows application.

## Choose by task and file format

For a short note, start with the [online notepad guide](/guides/online-notepad). For an editable Word document, use the [DOCX workflow](/guides/open-docx-online). For a comparison of lightweight writing and advanced Office features, see [WordPad versus Microsoft Word](/guides/wordpad-vs-microsoft-word).

Do not assume an online editor opens every file the desktop WordPad once handled. EDTRpad does not directly import RTF or legacy DOC files; convert those with a compatible application first and keep the original.
