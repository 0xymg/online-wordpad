A Chromebook can use EDTRpad through its browser without installing a Windows application. It is useful for everyday writing, short assignments and editing a DOCX copy.

## Open a file from your Chromebook

Start [EDTRpad](/pad), then choose **File → Open** and select the supported file through the system file picker. Where the picker can browse depends on your device and school or work policies.

Importing DOCX brings its content into the editor; it does not establish a live link to the original file in Drive. Read [opening DOCX online](/guides/open-docx-online) for conversion limits and review steps.

## Plan where the finished file goes

Export DOCX for another editor or PDF for a finished submission. Check the downloaded file and move it to the location you normally use for coursework or work. The [student workflow](/guides/wordpad-for-students) includes a submission checklist.

Guest autosave belongs to the current browser profile. Managed devices can clear local data, and a guest session should not be your only copy. An optional EDTRpad account enables document sync, subject to your organization allowing access.

## When Google Docs fits better

For classmates editing simultaneously or a teacher leaving suggestions in a shared document, Google Docs may be the appropriate tool. EDTRpad is focused on individual writing and file export, not live collaboration.

See the [Google Docs alternative guide](/guides/google-docs-alternative) to compare those workflows. Keep a network connection available to load the editor; do not assume an offline restart will recover everything you need.
