A browser text editor lets you write without installing a desktop application. EDTRpad focuses on formatted documents rather than code: paragraphs, headings, tables, images and downloadable files.

## Pick the right kind of editor

For prose that needs a readable layout, use a rich text editor. For source code or configuration files, choose a code editor that preserves syntax and offers developer tools. EDTRpad is not an IDE.

If the distinction is new, [rich text editing](/guides/rich-text-editor-online) explains what formatting adds, while [online notepads](/guides/online-notepad) covers simpler text workflows.

## What runs in the browser?

You edit the document in your browser. Guest documents are saved in browser storage; signed-in documents can sync through the service. DOCX import converts the selected file into editable content, and export creates a new file. It is incorrect to describe every workflow as “no backend” or “nothing ever leaves the device”.

On a shared computer, closing the tab is not the same as deleting a guest document. Keep your own export and remove any local document you should not leave behind.

## A useful browser workflow

1. [Open the editor](/pad) with a network connection.
2. Write a draft using headings and lists.
3. Import existing material through **File → Open** when needed.
4. Review the result and export a DOCX or PDF.

A browser interface removes the installation step, but browser storage is not a backup service. Read the [no-login guide](/guides/wordpad-no-login) before relying on a guest copy, and the [Word alternative comparison](/guides/online-word-alternative) if your document needs advanced Office features.
