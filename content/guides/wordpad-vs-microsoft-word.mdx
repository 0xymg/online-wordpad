**WordPad is a lightweight desktop editor; Microsoft Word provides a broader document-creation and review environment.** EDTRDocs is an independent browser editor for everyday writing, rather than a Microsoft WordPad product.

If you are looking specifically for a browser replacement, start with [free online Word alternatives](/guides/online-word-alternative). This page compares the jobs these editors are suited to.

## The practical differences

| Need | Classic WordPad | EDTRDocs | Microsoft Word |
|---|---|---|---|
| Basic text formatting | Yes | Yes | Yes |
| Create and edit tables | Limited | Yes | Yes |
| Save an editable document | Device files | DOCX and other exports | Word document formats |
| Work in a browser | No | Yes | Word for the web |
| Work without an editor account | Yes | Guest mode | Depends on edition and licensing; web apps use an account |
| Macros or mail merge | No | No | Available in supported desktop workflows |
| Complex Word layouts | Limited | Import and export need review | Best checked in Word itself |

Microsoft publishes a [web-versus-desktop feature comparison](https://support.microsoft.com/en-gb/word/word-features-comparison-word-for-the-web-vs-desktop). Features vary by Word edition; Word for the web should not be treated as identical to desktop Word.

## Do you have to pay to use Word?

Not necessarily. Microsoft offers free web apps with a Microsoft account. Desktop apps and subscription services have different licensing. See Microsoft's [free web apps and subscription explanation](https://support.microsoft.com/en-us/accounts-billing/subscriptions/what-s-the-difference-between-a-microsoft-365-subscription-and-free-web-apps) for the current distinction.

EDTRDocs is another free browser option. You can start as a guest, use the toolbar or slash menu and export your writing. Its appeal is the workflow, not a claim that every other document editor costs money.

## When a simpler editor is enough

A personal letter, meeting notes or a short report often needs headings, paragraphs, lists and perhaps a table or image. EDTRDocs supports those tasks, with browser saving for guests and account sync when signed in.

For an existing Word file, follow [how to open DOCX online](/guides/open-docx-online). Importing creates editable content; it does not guarantee that every layout feature will match Word. Keep and review the original if formatting is important.

## When Word is the safer fit

Use Word when the document depends on Word-specific features such as macros, mail merge, advanced fields or an established tracked-changes workflow. The same applies when a client supplies a strict template that must round-trip through Word without unexpected changes.

For shared live editing, consider the collaboration tools your team already uses. A lightweight individual editor cannot replace every part of that workflow.
