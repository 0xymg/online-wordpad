**You can open a DOCX file online without installing Microsoft Word.** In EDTRpad, select a `.docx` file from your device, read or edit its imported content, then download a new copy. Guest editing does not require an account.

[Open the DOCX editor](/pad), then choose **File → Open**. If you are signed in and see the welcome screen, you can also use **Open a file from your device** there.

## How to open a DOCX file online

1. Open [EDTRpad's browser editor](/pad).
2. Choose **File → Open** in the menu bar.
3. Select a file ending in `.docx` from your computer or phone.
4. Wait for its content to appear, then check the text, tables and images.
5. Make any changes with the toolbar or `/` command menu.
6. Choose **File → Export → Word (.docx)** to download an editable copy, or choose PDF for a fixed-layout copy.

The file picker opens on your device. Importing creates an EDTRpad document; it does not modify the original Word file. Export creates a separate download, so keep the original until you have reviewed the result.

## Is it a DOCX viewer or a DOCX editor?

EDTRpad lets you read and edit the imported content. It is useful when you need the text of a document, want to revise a letter, or need to change a simple table before sending a new copy.

It is not a pixel-for-pixel Word viewer. If you only need to see exactly how a document was laid out, ask its sender for a PDF or check it in Word. Importing into an editor and viewing the original page layout are different tasks.

## What formatting should you check?

EDTRpad converts DOCX content into its editor format. Text, common emphasis, headings, lists, tables and images can be imported, but the result depends on how the original document was built.

| Check after opening | Why it matters |
|---|---|
| Headings, lists and paragraph spacing | Word styles can map differently in another editor. |
| Table widths and cell layout | Complex table designs may need adjustment. |
| Images and their placement | Floating or anchored objects may not retain the same position. |
| Fonts, page breaks and page count | Fonts and page layout can change line wrapping and pagination. |
| Headers, footers, fields and review markup | Do not assume every advanced Word element will be preserved. |

For a résumé, invoice or form with strict layout requirements, review the exported file as well as the imported document. See the [Word alternative guide](/guides/online-word-alternative) for when a simpler editor is a good fit.

## Does the file get uploaded?

The DOCX conversion runs in your browser. With guest editing, the imported document is saved in that browser's local storage. If you use a signed-in account, the document can be saved and synced to your account on the server.

Local browser storage is not the same as a backup. Clearing site data, switching browsers or using a private browsing session can affect whether the saved document is available later. Export a copy you want to keep. Closing a normal browser tab does not by itself delete the locally saved document.

## What if the file will not open?

- **Check the extension.** The supported Word input is `.docx`. Older `.doc` files and macro-enabled `.docm` files are not supported DOCX inputs. Renaming the extension does not convert a file.
- **Check whether it is protected.** EDTRpad does not provide a password-unlock workflow for encrypted Word files. Use the originating application or ask the sender for an accessible copy.
- **Try the original application.** If Word cannot open the file either, it may be incomplete or damaged. Download it again or ask for another copy.
- **For a layout problem, keep the original.** Repeated import and export is not a reliable way to repair a complex document.

## Other ways to open Word files in a browser

Microsoft provides Word for the web through its [free web apps](https://support.microsoft.com/en-us/accounts-billing/subscriptions/what-s-the-difference-between-a-microsoft-365-subscription-and-free-web-apps). Google Docs can also edit Office files uploaded to Drive and save changes in the original Office format, as described in [Google's Office-file documentation](https://support.google.com/docs/answer/9406611?hl=en).

Choose EDTRpad for a straightforward browser editing workflow with optional sign-in. Choose the original application when preserving advanced document features is the priority.
