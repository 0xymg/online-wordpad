Your first EDTRDocs document needs three things: a clear structure, a place to save it and a format to share it in. This walkthrough covers all three without installing a desktop application.

## Create a short document

1. [Open EDTRDocs](/pad) and start a blank document.
2. Give it a recognizable title, such as “Project notes — October”.
3. Write a short opening paragraph before worrying about fonts.
4. On a new paragraph, type `/` and choose **Heading 2** for the next section.
5. Add a bullet list for separate points. Use numbered lists when order matters.

The toolbar remains available if you prefer visible controls. The command menu is another way to reach common actions, not a replacement for every toolbar option.

## Add structure only where it helps

Use a [table](/guides/insert-table-online-editor) for information with repeated fields, such as task, owner and due date. For a few unrelated notes, a list is easier to read. Add an [image](/guides/how-to-add-image-online) when it explains something the text cannot.

## Save, then make a portable copy

As a guest, your document is saved in this browser. Signing in enables account sync across devices. Exporting creates a separate file you can keep or send; it is different from autosave.

Choose **File → Export → Word (.docx)** for an editable copy. Reopen that copy if formatting matters to the recipient. The [DOCX export guide](/guides/export-to-word-docx-online) covers this handoff.

## Check before printing

Read the document once from beginning to end. Check headings, image sizes and tables, then choose **File → Print**. Use the [printing guide](/guides/print-document-browser) to review margins and page breaks before sending it to a printer.
