For a typing session, the most useful setup is a readable page with few decisions to make. EDTRDocs lets you draft in the browser and apply more detailed formatting afterward.

## Set up before you start

[Open a blank document](/pad), give it a recognizable name and choose a comfortable zoom level. Begin with ordinary paragraphs. You can use the default Calibri font; when Calibri is unavailable on the device, the editor has a fallback.

Write the first pass without repeatedly adjusting alignment or colors. Add a short heading when the subject changes, using `/` or the toolbar. The [simple-editor guide](/guides/simple-text-editor) describes this minimal workflow.

## Revise in a separate pass

Read each paragraph for one main point. Split long sections and turn sequences into numbered lists. Select key phrases for bold rather than emphasizing whole paragraphs.

Use [keyboard shortcuts](/guides/wordpad-keyboard-shortcuts) for frequent edits, and undo an accidental change before continuing. Browser spell-check behavior depends on your browser and language settings; do not treat it as a complete proofreading pass.

## Finish with a file you can keep

Autosave keeps guest writing in the current browser, while signed-in accounts add document sync. For a typing exercise or important draft, also export your own copy.

Choose TXT for plain words without formatting, or [DOCX](/guides/export-to-word-docx-online) when headings and formatting matter. EDTRDocs is a writing editor, not a typing-speed test: use a dedicated exercise tool if you need measured accuracy or words-per-minute scoring.
