A simple text editor is most useful when it helps you finish a small piece of writing without reorganizing your whole workflow. In EDTRpad, you can keep the document as plain or as structured as the task requires.

## Use the smallest useful structure

[Open a blank document](/pad), add a title and write short paragraphs. Use a heading when the topic changes. Use bullets when the reader should scan separate points.

Do not add a table just to align a few words. Reserve tables for repeated fields, as explained in the [table guide](/guides/insert-table-online-editor). The [typing guide](/guides/wordpad-typing) covers drafting before formatting.

## Plain text or rich text?

Plain text is useful for words that will be pasted elsewhere. Rich text adds headings, emphasis and other document elements. EDTRpad supports rich text, but you can export TXT when only the words matter.

TXT will not preserve images, fonts or table layout. Use [DOCX export](/guides/export-to-word-docx-online) if the next person needs an editable formatted document.

## Keep the saving choice simple too

Guests save in the current browser. Use an optional account for sync across devices, or keep exported files yourself. Read [no-login saving](/guides/wordpad-no-login) before relying on a shared computer or a private browser session.

If you need source-code editing, use a tool built for code. A simple document editor and a programming editor solve different problems even when both accept typed text.
