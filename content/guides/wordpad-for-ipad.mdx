EDTRDocs lets you write and edit documents in an iPad browser. A hardware keyboard helps with longer drafts, while the visible toolbar is useful when you are working with touch.

## Make room for the page

[Open the editor](/pad) and try landscape orientation for wider tables or longer lines. Start with short paragraphs and headings before adding more complex layout. On-screen keyboard height can reduce the visible page, so move through the document in small sections.

If a shortcut is unavailable, use the toolbar or File menu. The [first-document guide](/guides/how-to-use-wordpad-online) explains the same actions without requiring keyboard shortcuts.

## Import and export through Files

Use **File → Open** to select a supported document from the locations available in your iPad’s file picker. For a DOCX, check the imported headings, images and tables before editing. See [DOCX import](/guides/open-docx-online) for limitations.

When finished, export a copy and confirm where your browser saved or offered to share it. Browser and iPadOS versions can present these controls differently. Reopen the downloaded document if it is important.

## Save beyond the tab

Guest documents are stored in the current browser. Switching browsers or clearing website data does not preserve that local copy. Sign in for account sync, or keep an [exported Word file](/guides/export-to-word-docx-online).

For a complicated page layout or very large table, finishing the document on a larger screen may be more comfortable. The [printing guide](/guides/print-document-browser) helps with the final page check.
