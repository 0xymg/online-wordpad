Use a table when your document repeats the same fields: a schedule, a list of responsibilities or a comparison. EDTRDocs supports editable tables in the browser, unlike the classic WordPad workflow many people remember.

## Insert a table

1. [Open EDTRDocs](/pad) and place the cursor where the table belongs.
2. Type `/table` and choose **Table** from the command menu. This inserts a 3 × 3 table.
3. Alternatively, use the toolbar’s table grid picker to choose dimensions before inserting.
4. Enter short labels in the first row, then fill the rows below.

For a meeting, try three columns: **Task**, **Owner**, **Due**. That makes responsibility clearer than an unstructured paragraph. See [meeting notes](/guides/wordpad-for-notes) for a broader note-taking workflow.

## Edit the structure

Use the table controls to add or remove rows and columns. Press Tab to move forward between cells, or Shift+Tab to move back. At the last cell, Tab can add another row. Keep header labels brief so the table does not become unnecessarily wide.

Select text within a cell to apply bold or other formatting. Use column resizing when a long description needs more room than a short date.

## Check the exported result

A table in the editor is not a guarantee that every destination application will lay it out identically. Export a [Word copy](/guides/export-to-word-docx-online), reopen it and check column widths and wrapping. Before printing, inspect the [page preview](/guides/print-document-browser), especially when a table crosses a page boundary.
