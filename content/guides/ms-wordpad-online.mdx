EDTRDocs is an independent online editor for WordPad-style writing. It is not “Microsoft WordPad Online”, and using it does not require installing a Microsoft desktop application.

## Separate the product names

The former Windows WordPad, Microsoft Word and EDTRDocs are different products. Word offers web and desktop experiences; the old WordPad was a Windows application. EDTRDocs runs at wordpad.info and is developed by 312.

For context, see [what WordPad was](/guides/what-is-wordpad). If you are looking for Word itself, the [online Word alternative comparison](/guides/online-word-alternative) explains where EDTRDocs fits and where it does not.

## Use EDTRDocs for a straightforward document

[Open the editor](/pad), write paragraphs, apply headings and add lists. Import a supported DOCX with **File → Open** or begin from a blank page. Use the toolbar or `/` command menu for common formatting actions.

Guest documents save in your browser. Signing in adds account sync; it does not require a Microsoft account to begin a guest draft.

## Check file compatibility

EDTRDocs does not run Word macros or guarantee identical layout for complex Word files. It also does not directly import legacy DOC or RTF. Use the [DOCX guide](/guides/open-docx-online) for supported inputs and the [WordPad replacement checklist](/guides/wordpad-replacement) if you have older files to move.
