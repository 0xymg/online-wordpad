Rich text keeps meaning and presentation together: a heading is a heading, a list has separate items, and bold text carries emphasis. EDTRDocs gives you those document tools in a browser.

## Format the structure first

Start with a title and short paragraphs. Apply heading styles to major sections, then use bullets for related points or numbers for a sequence. Changing font size alone may make text look like a heading without giving it the same document structure.

Type `/` to choose a heading or list, or use the toolbar. Follow the [first-document guide](/guides/how-to-use-wordpad-online) for a complete example.

## Add visual information deliberately

A [table](/guides/insert-table-online-editor) works well when each row has the same fields. An [image](/guides/how-to-add-image-online) is useful for a diagram or photograph. Keep both within the page width and check them again after exporting.

Use bold sparingly to identify decisions, labels or important phrases. A document with every sentence emphasized is harder to scan. Prefer one body font and a consistent heading hierarchy.

## Choose an output that keeps what matters

DOCX keeps an editable document; PDF is useful for sharing a page layout. Plain text drops rich formatting and embedded images. HTML and Markdown serve different publishing workflows and should be checked in their destination application.

Guest editing saves in the current browser, while an account adds sync. Neither choice changes the need to review an exported file. See [DOCX export](/guides/export-to-word-docx-online) for a practical check before sending a document.
