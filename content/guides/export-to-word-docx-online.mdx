**EDTRpad can export your document as an editable Word file without Microsoft Office installed.** Use DOCX when the recipient needs to keep editing, or PDF when you want to share a fixed-layout copy.

Already have a Word file you want to edit? Start with [how to open DOCX online](/guides/open-docx-online). This guide covers downloading a document after writing or editing it.

## How to export to Word

1. Open your document in [EDTRpad](/pad).
2. Choose **File → Export → Word (.docx)**.
3. Save the download when your browser prompts you, or find it in your browser's download location.
4. Open the downloaded file to review it before sharing.

The download uses your document title as its filename. It creates a separate file; it does not overwrite a DOCX file you previously imported.

## What does DOCX export include?

The exporter supports text formatting, headings, lists, tables, images and page breaks. Fonts, sizes, colors and highlights are included where supported by the editor's document model.

Check the result in the recipient's application when layout matters. A missing font can change line wrapping; different word processors can paginate the same content differently. An imported Word document may also have lost unsupported features before export. Exporting it again does not restore those features.

For a résumé, designed form or complex report, keep the original file and compare it with the exported copy.

## Opening the result in Word or Google Docs

Open the downloaded `.docx` in Microsoft Word as you would another document. Google Docs can also edit Office files uploaded to Drive. Its [Office-file documentation](https://support.google.com/docs/answer/9406611?hl=en) explains the difference between editing an Office file directly and converting it into a native Google Doc.

If you need a review workflow with tracked changes or simultaneous editing, choose an application that supports it. See the [Google Docs alternative comparison](/guides/google-docs-alternative) for those trade-offs.

## DOCX or PDF?

| Choose | When |
|---|---|
| DOCX | Someone needs to edit the text, tables or formatting. |
| PDF | You want to share a fixed-layout copy for reading or printing. |
| Plain text or Markdown | You need the content for another writing or publishing tool. |
| HTML | You need document content in a web format. |
| RTF | The recipient needs a rich-text format supported by their application. |

All of these downloads are available through **File → Export**. An export is a useful backup even when browser autosave or account sync is enabled.
