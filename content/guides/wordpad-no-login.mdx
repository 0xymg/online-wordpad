You can write in EDTRDocs without signing in. Guest editing is useful for a quick document, but understanding where it saves matters more than skipping the login screen.

## What happens to a guest document?

Edits are saved in browser storage on the device and profile you are using. Returning to that same browser can restore the document. Another browser, a different profile or a different device does not automatically share that copy.

Clearing site data can remove guest documents. Private browsing may discard them when the private session ends. Closing a normal tab, on the other hand, does not necessarily delete them.

## Use guest mode for a complete task

1. [Open EDTRDocs](/pad) and draft your document.
2. Give it a recognizable title and use headings or lists where helpful.
3. Choose **File → Export** to create a file you can keep.
4. Confirm the downloaded file opens before leaving the device.

The [DOCX export guide](/guides/export-to-word-docx-online) explains editable copies. Use TXT for plain words or PDF when you need a finished document to read.

## When to create an account

An account is useful when you want document sync across devices. That is different from a backup you store yourself, and it does not enable live shared editing.

On a public computer, export what you need and remove documents you should not leave in local storage. Read [no-sign-up editing](/guides/text-editor-no-sign-up) for a shared-device workflow, or [Google Docs alternatives](/guides/google-docs-alternative) if you are choosing between account-based services.
