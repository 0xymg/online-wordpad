To open a WordPad-style editor online, go to EDTRDocs in your browser. To open an existing document, first check its file type: these are different starting points.

## Open a blank page

Visit [the editor](/pad) and start writing. You can work as a guest and use headings, lists and formatting controls without installing an application.

The [first-document guide](/guides/how-to-use-wordpad-online) explains the next steps. Guest documents save in the current browser, while signing in adds document sync.

## Open an existing file

Choose **File → Open**, then select DOCX, TXT, Markdown or HTML from your device. Markdown input is treated as text rather than automatically becoming a fully formatted Markdown document.

For a DOCX, review headings, tables, images and spacing after import. The [DOCX opening guide](/guides/open-docx-online) explains why complex Word layout may change.

## If the file does not open

Check the extension and make sure the file is not an unsupported legacy format. EDTRDocs does not directly import RTF, DOC or WRI, and renaming one of those files to DOCX will not convert it.

Use a compatible application to create a supported copy, keeping the original. The [WordPad replacement guide](/guides/wordpad-replacement) provides a migration checklist.

After editing, use [File → Export](/guides/export-to-word-docx-online) to download a new copy. Opening and editing a file in the browser does not automatically overwrite the file you selected from your device.
