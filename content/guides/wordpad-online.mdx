EDTRDocs is an online WordPad for everyday documents: letters, notes, reports and editable Word files. It is an independent browser editor developed by 312, not a Microsoft product.

## Start with a document

[Open the editor](/pad) and begin with a blank page, or choose **File → Open** to bring in an existing file. You can write as a guest. Use headings for sections, lists for action items and the toolbar for font and paragraph formatting.

Type `/` in the document to find commands such as Heading 2 or Table. The [first-document walkthrough](/guides/how-to-use-wordpad-online) takes you from a blank page to an exported copy.

## Choose how to keep your work

Guest documents are saved in the current browser. Returning in the same browser profile lets you continue, but clearing site data or using a different device can leave that copy unavailable. An optional account adds server-backed document sync.

Neither mode replaces a copy you control. Export a DOCX for further editing or a PDF for distribution. See [exporting to Word](/guides/export-to-word-docx-online) for the steps and checks.

## Know the boundaries

EDTRDocs has a formatting toolbar as well as slash commands. It supports solo writing, not live coauthoring or Google Docs suggestion threads. Imported DOCX content may need layout adjustments; [opening DOCX online](/guides/open-docx-online) explains what to review.

Load the editor with an internet connection. Do not rely on a fresh offline visit to retrieve a document. For Windows users looking for the removed desktop app, see [WordPad on Windows 11](/guides/wordpad-windows-11).
