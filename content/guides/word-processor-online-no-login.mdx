A word processor without a login should still let you finish the job: write, format and take the document away. EDTRDocs supports that workflow through guest editing and file export.

## Create a document with structure

Start in [EDTRDocs](/pad) with a title, an introductory paragraph and headings for each main section. Use a numbered list for instructions and a table only when information repeats across rows.

The [rich text guide](/guides/rich-text-editor-online) explains those choices. You can use the toolbar or type `/` to find common commands.

## Bring in existing work

Choose **File → Open** for DOCX or a supported text file. Importing creates editable content in EDTRDocs; it does not continuously update the original file. Check headings, tables and images before making changes.

Follow [opening DOCX online](/guides/open-docx-online) if the file came from Word. Complex layout, unsupported file types and encrypted documents need a different workflow.

## Leave with a usable copy

Use **File → Export → Word (.docx)** when the next person needs to edit the document. Use PDF when they only need the finished pages. Inspect the exported copy before sending it.

Guest autosave is browser storage, not a cross-device account. See [no-login saving](/guides/wordpad-no-login) for what persists and what can disappear. If your main need is real-time collaboration, compare the [Google Docs workflow](/guides/google-docs-alternative) before choosing a solo editor.
