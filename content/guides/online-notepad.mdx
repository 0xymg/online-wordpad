An online notepad is useful for capturing a thought before it disappears. EDTRDocs can serve that purpose, with optional formatting when a quick note grows into a document.

## Capture first, organize second

[Open the editor](/pad) and write the main idea in the first line. Add supporting points below it. For a task list, keep one action per item rather than packing several actions into a paragraph.

If the note becomes longer, add headings for separate topics. See [note-taking in EDTRDocs](/guides/wordpad-for-notes) for a structure that separates context, decisions and next steps.

## Choose how to reuse the note

Copy the text into another application when you only need the words. Export TXT for a plain file, or DOCX when headings and formatting matter. An export is a separate copy, not a connection that keeps another app updated.

The [simple text editor guide](/guides/simple-text-editor) explains the plain-versus-rich-text choice. For code snippets, use a dedicated code editor when exact syntax and developer tools are important.

## Understand persistence

Guest notes save in browser storage. They do not automatically appear in another browser, and clearing site data can remove them. Signed-in accounts add server-backed document sync, so it is inaccurate to describe the entire service as having no server or accounts.

On a shared device, close the task by exporting what you need and removing local notes you should not leave behind. Read the [guest-saving guide](/guides/wordpad-no-login) for the details.
