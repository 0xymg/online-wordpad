**EDTRpad is a free online Word alternative for letters, notes, short reports and everyday document edits.** It runs in your browser, opens `.docx` files and exports editable Word documents. You can start without an account; an optional account adds document sync across devices.

[Open the online document editor](/pad) to start a blank document, or follow the [DOCX opening guide](/guides/open-docx-online) if someone has sent you a Word file.

## What can you do without Microsoft Word?

You can write and format text with the toolbar, or type `/` to open the command menu. EDTRpad includes headings, font controls, lists, tables, images and page breaks. You can print a document or download it as DOCX, PDF, RTF, HTML, Markdown or plain text.

For example, to prepare a one-page letter:

1. Open the editor and type your letter.
2. Add a heading and adjust the font, spacing and alignment with the toolbar.
3. Use **File → Export → Word (.docx)** if the recipient needs an editable file.
4. Use PDF export or print preview when the page layout matters more than further editing.

Writing is saved automatically. Without an account, that saved copy belongs to the current browser and device. Download a copy before clearing browser data or moving to another computer.

## Which Word alternative fits your task?

| Your task | A suitable option | What to consider |
|---|---|---|
| Write a letter or revise a short document without signing in | EDTRpad | Guest documents save in the current browser; export a copy to keep elsewhere. |
| Work on a Word document within Microsoft's ecosystem | Word for the web | Microsoft's free web apps are available with a Microsoft account. |
| Edit a shared document with other people at the same time | Google Docs | Built for shared editing and cloud-based documents. |
| Preserve a complex Word document's layout and advanced features | Microsoft Word | Check the document in the application it was created for. |

Word for the web is also a free option: a paid desktop subscription is not required for all browser-based Word editing. Microsoft explains the distinction in its [comparison of free web apps and Microsoft 365 subscriptions](https://support.microsoft.com/en-us/accounts-billing/subscriptions/what-s-the-difference-between-a-microsoft-365-subscription-and-free-web-apps).

EDTRpad's main difference is its lightweight workflow and optional sign-in, rather than an exclusive claim to free document editing.

## Can it open and save DOCX files?

Yes. Choose **File → Open** to select a `.docx` file from your device. EDTRpad imports its content into an editable document. After making changes, choose **File → Export → Word (.docx)** to download a new copy. Importing a file does not overwrite the original on your device.

This is a content-editing workflow, not a guarantee that every Word layout feature will survive unchanged. Complex tables, exact pagination, section layouts and embedded objects can need adjustment. Review an imported document before sending it, especially a résumé, form or designed template.

See [how to open a DOCX file online](/guides/open-docx-online) for the full workflow and [exporting to Word](/guides/export-to-word-docx-online) for download options.

## When should you keep using Word?

Keep Word for documents that depend on its advanced features or need an exact round trip through Microsoft's format. EDTRpad does not replace Word macros, mail merge or a tracked-changes review workflow. It also does not offer simultaneous multiplayer editing.

For a contract with revision history, a complex thesis template or a tightly specified business form, test a copy first. Microsoft's [web and desktop feature comparison](https://support.microsoft.com/en-gb/word/word-features-comparison-word-for-the-web-vs-desktop) can help you decide which Word version you need.

## Common questions

### Is this Microsoft Word Online?

No. EDTRpad is an independent editor at wordpad.info. It is not a Microsoft product, although it can import and export DOCX files.

### Do I need to create an account?

No account is needed for guest editing. Sign in if you want your documents to sync through an EDTRpad account. Browser-only saving and account sync are different storage modes.

### Is it a Google Docs alternative too?

For individual writing and editing, it can be. For shared live editing, Google Docs serves a different need. Read the [Google Docs alternative guide](/guides/google-docs-alternative) before switching a team workflow.
