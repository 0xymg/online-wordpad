“Word Pad” is often used as another spelling of WordPad, the former Windows document editor. On this site, the browser editor is called EDTRDocs and is developed independently by 312.

## Find the workflow you meant

If you want a blank document, [open EDTRDocs](/pad). If you are wondering what happened to the Windows application, read [WordPad on Windows 11](/guides/wordpad-windows-11). If you have an existing Word file, start with [opening DOCX online](/guides/open-docx-online).

Those paths lead to different tasks; you do not need to reinstall the old Windows app just to begin a new browser document.

## Write and format a simple document

EDTRDocs supports headings, lists, tables and images. Use the formatting toolbar or type `/` for the command menu. Guest writing saves in the current browser, and an optional account adds sync across devices.

The [first-document walkthrough](/guides/how-to-use-wordpad-online) takes you through a short draft. For a plain note, you can keep formatting minimal and export TXT when only the words matter.

## Keep the product distinction clear

EDTRDocs is not Microsoft Word and does not promise every Office feature or exact conversion of complex files. It also does not directly import all historical WordPad formats.

Before moving an archive of older documents, follow the [replacement checklist](/guides/wordpad-replacement). For everyday writing, export a DOCX or PDF when finished and check that the copy opens as expected.
