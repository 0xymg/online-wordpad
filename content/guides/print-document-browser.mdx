Printing is a separate check from writing. A document that looks comfortable in the editor can still need different paper size, margins or page breaks in the browser’s print dialog.

## Open the print preview

1. Finish your draft in [EDTRpad](/pad).
2. Choose **File → Print**. You can also use the editor’s print shortcut, Ctrl+P on Windows or Command+P on macOS.
3. Select the intended printer or a PDF destination, if your system provides one.
4. Check the paper size, orientation, margins and page range before confirming.

The exact dialog depends on your browser and operating system. Do not assume a setting from the last print job suits the current document.

## Look for these layout problems

Check for a heading left alone at the bottom of a page, a wide table clipped at the edge, and an image that creates a large blank area. Remove accidental blank paragraphs before trying to fix spacing with margins.

Use an intentional page break when a new section must begin on a new page. For table-specific issues, see [tables in EDTRpad](/guides/insert-table-online-editor); for oversized images, see [adding images](/guides/how-to-add-image-online).

## PDF or editable Word file?

A PDF is useful when the recipient should read a fixed document. A DOCX is useful when they need to edit it. EDTRpad also offers PDF in the export menu; browser printing and file export are different routes, so review the resulting file rather than assuming they are identical.

Keep an [editable DOCX copy](/guides/export-to-word-docx-online) alongside the finished PDF if you expect revisions. Saving a guest document in the browser does not create either downloaded file automatically.
