Using WordPad-style tools on the internet means opening an editor through a website instead of launching the old Windows app. EDTRDocs provides that browser workflow for individual documents.

## What you need to begin

Use a supported modern browser and a connection to load [EDTRDocs](/pad). You can begin as a guest, write formatted text and export a copy. An optional account adds document sync across devices.

Start with the [first-document walkthrough](/guides/how-to-use-wordpad-online) if you are unfamiliar with headings, slash commands or the export menu.

## Internet access and saved work are different

A guest document is stored in the current browser, not automatically attached to every computer you use. Signing into an account provides a different saving workflow through the service.

Do not treat local autosave as a guaranteed offline backup. Keep an exported file you can locate. The [guest-saving explanation](/guides/wordpad-no-login) covers private sessions, cleared site data and shared devices.

## Open and send files deliberately

Use **File → Open** for supported inputs, including DOCX. Review the result because conversion may change complex layout. Export creates a new file rather than overwriting the original automatically.

Follow the [DOCX guide](/guides/open-docx-online) for import, then the [export guide](/guides/export-to-word-docx-online) for handoff. If you need multiple people editing the same document at once, read the [Google Docs comparison](/guides/google-docs-alternative) before choosing a solo-writing tool.
