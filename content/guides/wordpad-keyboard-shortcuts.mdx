Keyboard shortcuts help when you are editing a long draft, but they only work as intended when focus is in the document. EDTRpad combines familiar formatting shortcuts with a slash command menu.

## Everyday editing shortcuts

Use Ctrl on Windows and Linux, or Command on macOS, for the modifier shown below.

| Action | Windows / Linux | macOS |
|---|---|---|
| Bold | Ctrl+B | Command+B |
| Italic | Ctrl+I | Command+I |
| Underline | Ctrl+U | Command+U |
| Undo | Ctrl+Z | Command+Z |
| Redo | Ctrl+Shift+Z | Command+Shift+Z |
| Insert or edit a link | Ctrl+K | Command+K |
| Save the current document now | Ctrl+S | Command+S |

Select text before changing its formatting. Without a selection, a formatting command can affect what you type next. Save updates the document’s saved state; it does not mean “download a DOCX”. Use [File → Export](/guides/export-to-word-docx-online) for a portable file.

## Use slash commands for structure

Type `/` in the document to open the menu. Search for **Heading 2**, **Bullet List** or **Table**, then choose the result. The [table guide](/guides/insert-table-online-editor) shows a concrete example.

## When a shortcut does something unexpected

Click back into the document and try again. Browser extensions, operating-system bindings and keyboard layouts can intercept key combinations. The toolbar and File menu provide visible alternatives.

For printing, choose **File → Print** if the browser shortcut opens a different workflow. The [printing guide](/guides/print-document-browser) explains what to inspect before confirming. On an iPad, use visible controls when no hardware keyboard is connected.
