WordPad is removed starting with Windows 11 version 24H2. An update can therefore leave you with documents but without the familiar application that used to open them.

## What changed?

Microsoft’s [removed-features documentation](https://learn.microsoft.com/en-us/windows/whats-new/removed-features) identifies WordPad’s removal in Windows 11 24H2 and Windows Server 2025. This is different from its earlier deprecation announcement.

Removing the application does not mean your documents have become a new file format. Check the file extension first: a TXT, RTF and DOCX need different handling. The [WordPad overview](/guides/what-is-wordpad) explains the distinction between the former Windows app and online alternatives.

## Open the file with a suitable editor

EDTRDocs can open DOCX, TXT, Markdown-as-text and HTML inputs. It does not directly import RTF, legacy DOC or WRI files. Do not rename an unsupported extension to DOCX; renaming does not convert the contents.

For a supported Word file, follow the [DOCX opening guide](/guides/open-docx-online). For RTF or another unsupported format, use an application that supports that format and save a compatible copy before importing.

## Choose a replacement for your work

For short formatted documents, [EDTRDocs](/pad) offers browser editing and downloadable copies. For advanced Word workflows or reliable offline desktop use, compare other tools against those requirements.

The [replacement guide](/guides/wordpad-replacement) gives you a migration checklist. Keep original documents until you have checked the converted and exported copies, especially when tables or page layout matter.
