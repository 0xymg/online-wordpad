EDTRDocs can help with class notes, short assignments and reports when you need a browser editor. Before writing, check your course’s required file format and formatting rules.

## Build an assignment outline

Start with the question you need to answer. Create headings for the main points and add evidence beneath each one. Keep sources next to the notes they support so you can build the required citations later.

Use the [first-document walkthrough](/guides/how-to-use-wordpad-online) for headings and lists. A [table](/guides/insert-table-online-editor) can organize a reading comparison, but it is not a substitute for explaining your conclusions.

## Match the submission requirements

If the course asks for an editable Word file, export DOCX. If it asks for PDF, export or print to PDF and inspect the result. Check the filename, page breaks, font size and image placement before uploading.

For complex citation management, tracked changes or strict institutional templates, use the tools your course requires. The [Word comparison](/guides/wordpad-vs-microsoft-word) explains why a browser editor does not replace every Word workflow.

## Keep a backup before the deadline

Guest work is saved in the browser you are using. School computers may clear their browser profiles, and private browsing may discard data when the session ends. Export a copy somewhere you can access later; an optional account also adds sync across devices.

Reopen the downloaded file before submission rather than relying only on the editor view. Follow [DOCX export checks](/guides/export-to-word-docx-online) and [printing checks](/guides/print-document-browser) for the final review.
