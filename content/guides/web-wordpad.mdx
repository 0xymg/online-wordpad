A web WordPad is a browser-based way to handle the small documents you might once have written in a lightweight desktop editor. At wordpad.info, that editor is EDTRpad, developed by 312.

## Use a bookmark as your starting point

[Open EDTRpad](/pad) and bookmark the editor if you use it regularly. A bookmark gets you back to the application; it is not a link that shares a particular guest document with another person.

Guest documents are stored in the browser profile where you wrote them. The [saving guide](/guides/wordpad-no-login) explains how that differs from account sync and exported files.

## Work with familiar document tools

Write paragraphs, use headings and lists, then add tables or images when they help. The toolbar provides visible controls, while `/` opens the command menu.

The [online WordPad guide](/guides/wordpad-online) introduces the main features. For an existing Word document, follow the [DOCX opening steps](/guides/open-docx-online) and inspect the conversion before editing.

## Take the document with you

Export a DOCX when you need an editable file or a PDF for finished pages. The exported file can be moved independently of the browser you used to write it.

Load the editor with an internet connection. A web app is not a promise that every future offline visit will work. If offline desktop use is essential, include that requirement when comparing [WordPad alternatives](/guides/wordpad-alternative).
