EDTRDocs’s editing interface has a page for your writing, a formatting toolbar and a File menu for document actions. Use slash commands to find common actions without leaving the text.

## Find the right control

Use the toolbar for font and paragraph formatting. Use headings and lists to give the document structure. For inserting a table, the grid picker offers dimensions while `/table` provides a quick starting table.

The [table guide](/guides/insert-table-online-editor) shows both approaches. The [shortcut guide](/guides/wordpad-keyboard-shortcuts) covers frequent formatting actions.

## Keep file actions separate

**Open** imports an existing file into the editor. **Export** downloads a new copy in a chosen format. **Print** opens a print workflow. Saving the current document is another action: guests save in the browser, and signed-in accounts can sync through the service.

For a concrete example, read [opening DOCX online](/guides/open-docx-online), then [exporting a Word copy](/guides/export-to-word-docx-online). The original file and the newly exported file remain separate.

## Work from content to presentation

Draft the main text first. Apply headings, check lists and review tables before adjusting the final page layout. This makes it easier to notice missing information instead of spending the first pass on appearance.

Start with the [beginner walkthrough](/guides/how-to-use-wordpad-online) if you want a sequence to follow from blank page to finished document.
