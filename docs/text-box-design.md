# Text boxes: first implementation

The first text box is an inline ProseMirror atom named `text_box`. Its paragraph is its page anchor, just like a fixed image. Position is measured in CSS pixels from the physical sheet's top-left corner. The model stores plain multiline `text`, `position: page`, `x`, `y`, a pixel-string `width`, numeric minimum `height`, `layer`, `textPlane`, font family/point size, text/background/border colors and padding. It does not create sections, references or advanced Word compatibility features.

The body is rendered as text, with `white-space: pre-wrap`, wrapping long words, the shared document font fallback and a fixed 1.2 line height. It never accepts raw HTML. `height` is a minimum: the frame grows vertically to display all content. Placement uses its actual measured height. A box taller than the sheet displays an explicit warning; the dialog explains that text must be shortened, resized or widened before printing. Content beyond a physical sheet is not guaranteed to print. This boundary is visible to users and does not discard model content.

Text editing is explicit: double-click or choose **Edit text** to open a multiline textarea. The dialog also exposes coordinates, minimum dimensions, font, colors and text plane, with a stale-document guard. Applying all changes is one undo step; cancel changes nothing. A dedicated **Move** button moves the selected box; four corner buttons resize it. Body clicks select and never start a drag. Move also supports arrow keys (Shift increases the step), and all handles offer keyboard access to the size dialog. A pointer gesture previews only DOM geometry and commits one model change when released; Escape, pointer cancellation and document replacement discard it. The existing layer panel provides access to fully covered and behind-text boxes. Controls occupy a separate sibling plane so behind-text artwork does not bury selection UI.

HTML contains one `data-edtr-textbox` JSON payload on the zero-size anchor plus a plain text frame. The schema sanitizes every imported attribute. The live editor and read-only print/PDF view use the same frame styles and pagination coordinates. Selection controls and overflow badges are editor-only UI and are excluded from output.

DOCX export replaces temporary bookmarks with native editable VML `v:shape` / `v:textbox` / `w:txbxContent`, using page-relative offsets, fixed width, minimum height and Word's fit-to-text option. The native content contains one Word paragraph per source line, preserving blank lines and whitespace. Supported font and color settings are native OOXML; supported model metadata lives in the shape's alternative-text attribute to preserve the fallback font stack and exact plain-box representation. Import reads the actual native text so edits made in Word are retained. Native VML or DrawingML `w:txbxContent` is extracted before Mammoth converts body content, replaced with temporary bookmarks and restored as text-box atoms afterward. AlternateContent fallback branches are deduplicated. This is plain-text import: heterogeneous rich formatting is reduced to the first run's supported font and color. Rotation, linked boxes, groups and shapes are outside this package.

Validation covers explicit editing versus movement, multiline/blank-line persistence, single undo/cancellation, size overflow, layer selection, native DOCX round trips and matching editor/print/PDF geometry. Local readiness and production verification are separate; no deployment is implied by the implementation.
